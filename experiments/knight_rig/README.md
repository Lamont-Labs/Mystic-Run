# Experimental painted Knight rig

Open `playable.tscn` in Godot 4.7.2 and press **F6**. Uses the actual game with
test-only progress. R cycles layered → skeletal → old cutout. Normal app startup
and all production artwork remain untouched.

This is one rear-view character, not a release or a completed animation pack.
See `docs/KNIGHT_LAYERED_RIG_EXPERIMENT.md` for reproduction, measured results,
art provenance and limitations.

The fourteen native 2D bones animate original painted parts from one atlas.
Run animation is continuous with planted ankles and projected limb shortening.
No entire character image is crossfaded to produce an action.

The source concept permits noncommercial game use only.
