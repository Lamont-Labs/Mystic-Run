# Mystic Run 0.6.0 — Adventure implementation

November 2, 2026 · Lamont Labs

Implemented horizontal-swipe combat, a separate thumb-steering fallback, three combat specials, three earned contextual traversal abilities, nine level-and-character secret routes and collectible treasures, fourteen achievements, persistent mastery, a collection journal and repeatable expeditions. The protected tutorial cannot grant mastery. Confirmed local-progress clearing removes both the current save's progress and its previous-save backup, while retaining accessibility and control preferences; errors leave a visible message.

The presentation includes animated playable runners, brighter scenery, floating lanterns, star pickups, comic impact feedback, bouncy menus, unique secret chamber meshes and reduced-motion support. An in-game privacy notice describes this offline build.

Local engine verification: 791 assertions passed (427 core, 38 gesture/course, 125 progression and secret-route, 148 navigation, 35 tilt/elevation, 18 animation). All three characters completed a scripted 3,600-tick basic-only run of about 1.31 km without damage, death or character handoff. Native GUI clicks also passed in a software-rendered desktop environment. Three character/level secret chambers were visually inspected with temporary in-memory mastery, including an actual motion recording. These are desktop checks, not physical-phone results.

A release APK and Play submission have different requirements. The signed APK is a development build for direct installation. See `GOOGLE_PLAY_READINESS.md` for the production AAB, hosted policy, Play Console and device checks still outstanding.
